# User Stories for Repair Shop App

1. [] Replace current sticky note system
2. [] employee login page.
3. [] Show a real-time open tickets page after login
4. [] Provide easy navigation & search for customers & tickets
5. [] Provide a logout option
6. [] Provide a way to remove employee access asap if needed
7. [] Customers have an ID, name , full address, phone, email , Submit Date & notes
8. [] Tickets have an ID, title, notes, created & updated dates
9. [] Tickets are either OPEN or COMPLETED
10. [] Tickets are assigned to specific employees
11. [] Users can have Employee, Manager, or Admin permissions
12. [] All users can create and view tickets
13. [] All users can create, edit and view customers
14. [] Employees can only edit their assigned tickets
15. [] Managers and Admins can view, edit, and complete all tickets
16. [] Light / Dark mode option requested by employees
17. [] Expects quick support if anything goes wrong with the app
